# Product

## Register

product

## Users

Single-player Windows users who maintain large local DNF NPK patch libraries. They work with mouse and keyboard, often paste long paths, repeat enable/disable and organization tasks, and need reliable feedback when filesystem operations affect real game files.

## Product Purpose

DNF Patch Manager is a local desktop workbench for scanning, organizing, previewing, enabling, disabling, and recovering user-owned DNF patch files. Success means that paths, current state, operation scope, and recovery outcomes are explicit before the user commits a filesystem change.

## Brand Personality

Quiet, precise, dependable. The interface should feel like a focused local tool that stays out of the way during repetitive maintenance work.

## Anti-references

Avoid marketing-page composition, decorative cards, ambiguous custom controls, oversized display typography, gratuitous motion, and visual effects that obscure filesystem state or operation feedback.

## Design Principles

- Make paths and state explicit.
- Keep repeated workflows dense, stable, and keyboard-friendly.
- Use accent color for focus, selection, and actionable feedback.
- Preserve reversibility and explain filesystem consequences before destructive actions.
- Prefer familiar controls and consistent component states over novelty.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard navigation, visible focus, readable contrast, long Chinese and Windows paths, Windows display scaling, and prefers-reduced-motion. Do not rely on color alone for enabled, conflict, or error states.
