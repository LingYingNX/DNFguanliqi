# 标题栏直角控制按钮设计

## 背景

自定义标题栏右上角的最小化、最大化和关闭按钮使用圆角，关闭按钮右侧还保留 12px 空隙，未与窗口右上边框对齐。

## 目标

- 三个窗口控制按钮为直角矩形。
- 保持当前 32px x 32px 控制按钮尺寸、图标、点击语义和悬停色彩。
- 去除控制按钮间距。
- 关闭按钮的右边缘与窗口右边缘对齐。

## 设计

仅调整标题栏控制区样式。`.window-controls` 保留标题栏内上下 2px 的垂直留白，但右侧内边距设为 0，按钮间距设为 0。`.window-control-button` 使用 0 圆角，保留透明默认背景、普通悬停背景和关闭按钮红色悬停背景。

不修改 `WindowTitleBar` 的按钮结构、窗口控制 IPC、拖拽区域或标题栏高度。关闭按钮贴齐窗口右边缘后，其他两个按钮自然连续排列在其左侧。

## 验证标准

- E2E 测试确认关闭按钮右边缘与视口右边缘的误差小于 1px。
- E2E 测试确认三个控制按钮的计算圆角为 0px。
- 现有最小化、最大化、还原、关闭和拖拽区域行为继续通过。
- TypeScript、定向 E2E、构建、定向 lint 和 `git diff --check` 通过。
