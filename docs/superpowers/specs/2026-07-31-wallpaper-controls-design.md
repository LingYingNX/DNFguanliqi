# 壁纸控制与槽位布局设计

## 背景

外观面板中的色温和位置控制目前没有形成可见效果，透明度默认值也不符合新的使用预期。壁纸槽位需要在保持现有宽度的情况下改成纵向滚动列表，以减少面板高度和视觉拥挤。

## 目标

- 色温滑块能够对当前壁纸产生冷暖变化。
- 左右移动和上下移动滑块能够对当前壁纸产生稳定、可见的平移效果。
- 默认透明度和“恢复默认”值为 `50`。
- 导入壁纸并激活后，壁纸控制项恢复为默认值，主题和颜色设置保持不变。
- 壁纸槽位保持现有宽度，缩略图比例为 `16:9`。
- 最多保留 5 个槽位，槽位纵向排列并在左侧区域内滚动。
- 空槽位显示加号并可点击导入；已有槽位显示缩略图。
- 删除按钮默认隐藏，在槽位悬停或键盘聚焦时于右侧显示。

## 设计

### 壁纸效果链路

`useAppearance` 继续把持久化外观设置转换为根元素 CSS 变量。新增色温滤镜变量或等价的滤镜片段，并将其与饱和度、对比度和模糊度组合到壁纸伪元素的 `filter` 中。色温的负值使用冷色方向，正值使用暖色方向，中间值不增加色温效果。

位置控制使用壁纸背景的 `background-position`，由左右和上下滑块分别控制 X/Y 取景位置。壁纸使用 `cover` 覆盖软件窗口，超出可视区域的图像仍保留，可通过位置滑块移入视野，同时不改变前景工作区的布局。

### 透明度

`defaultAppearanceSettings` 和 CSS 初始变量使用 `50`/`0.5`。面板重置直接使用该默认设置。导入 IPC 在导入并激活成功后重置全部壁纸控制项；如果后续步骤失败，恢复导入前的外观设置。

### 槽位布局

左侧槽位容器继续使用现有宽度。槽位自身使用 `aspect-ratio: 16 / 9`，并禁止压缩；容器设置固定可用高度和垂直滚动。每个槽位的选择按钮覆盖缩略图区域，空槽位渲染加号图标。删除按钮放在槽位右侧的绝对定位操作层，默认不可见，槽位 `:hover` 或 `:focus-within` 时显示。

### 错误处理

导入、激活、删除和外观更新沿用现有 IPC 错误返回及忙碌状态。位置和色温仅更新外观设置，不新增持久化字段或新的 IPC 通道。

## 验证标准

- 渲染器测试确认默认透明度为 `50`、重置为 `50`、色温和位置更新会提交对应持久化值。
- 渲染器测试确认空槽位有加号、已有槽位有图片、删除按钮存在但默认隐藏且悬停后显示。
- E2E 测试确认导入壁纸后主界面应用壁纸，色温/位置 CSS 变量存在，透明度为预期值，槽位区域可滚动且面板外部不出现黑色遮罩。
- TypeScript、构建、全量测试、集成测试、定向 lint 和 `git diff --check` 通过。
