# 补丁卡片与补丁组操作设计

## 目标

让补丁卡片和补丁组在网格、列表视图中都具备一致的可操作性：卡片比例保持 `4:3`，右下角开关控制启用状态，双击预览区域设置预览图；右键菜单提供移动、打组/进入组、加入预设、重命名、删除等操作，并支持 `Ctrl+G`、`F2`、`Delete` 快捷键。

## 已确认行为

- 普通补丁右键菜单按顺序显示：移动、打组、加入预设、重命名、删除。
- 补丁组右键菜单按顺序显示：移动、进入组、解散组、加入预设、重命名、删除。
- 右键菜单不包含剪切和粘贴；不维护剪贴板状态。
- `Ctrl+G` 仅在选中至少两个普通 NPK 补丁时打开打组对话框。
- `F2` 在单选普通补丁或补丁组时打开重命名对话框。
- `Delete` 删除当前选中项目，复用现有回收站流程，不直接删除文件。
- 开关复用现有批量启用/停用 IPC。点击开关只改变启用状态，不改变卡片选中状态。
- 双击 `.item-preview` 只打开现有预览选择流程；补丁和补丁组使用各自的 `kind` 与相对路径。
- “进入组”把当前组目录作为工作区扫描路径，显示组内 NPK；用户可通过侧栏系统入口或分类入口离开该目录。
- “解散组”把组内所有 NPK 移回父分类，然后删除 `.dnf-group.json` 和空组目录。目标目录存在同名 NPK 时整个操作失败且磁盘不变；组预览绑定被移除，NPK 预览绑定保持不变。
- 组内出现非 NPK、非 `.dnf-group.json` 文件时拒绝解散，避免静默丢失文件。

## 架构

### 核心文件事务

新增 `src/core/library/dissolve-group.ts`，负责校验组标记、读取组内 NPK、检查父目录目标冲突，并生成可回滚的文件事务：逐个移动 NPK、删除标记、删除空目录；补偿步骤按相反顺序恢复目录、标记和 NPK。`LibraryCommands` 暴露 `dissolveGroup`，便于核心集成测试直接验证文件树。

### 生命周期与 IPC

扩展 `LibraryLifecycleService` 的 `dissolveGroup`，把核心文件事务与启用记录迁移、预览绑定清理放进同一个事务。启用记录从 `group\\file.npk` 改为父分类的 `file.npk`，游戏目录目标保持不变。新增 `library:dissolve-group` IPC channel、请求 schema 和 preload 类型，主进程在已有 mutation mutex 中调用生命周期服务；没有游戏目录时仍完成文件和预览事务。

### 渲染器交互

`WorkspaceApp` 把解散、进入组和卡片级启用回调传给 `ItemWorkspace`。`ItemWorkspace` 管理菜单位置和关闭事件，右键前先确保项目已选中；菜单动作复用 `OperationDialogs` 或现有预设流程。新增 `group` 导航选择以扫描组目录，并在选择其他系统入口或分类时清除它。卡片开关使用原生 checkbox + 自定义 `.switch/.slider` 样式，阻止事件冒泡。

## 错误与恢复

- 输入路径仍由现有相对路径 schema 校验。
- 组标记无效、组路径不是组、父目录或目标文件不可访问、同名冲突、存在额外文件均返回明确 API 错误。
- 文件、安装记录和预览状态在同一事务中执行；任一步失败则按现有事务恢复机制回滚，失败回滚继续生成恢复日志。
- 只读恢复模式禁用右键变更、开关和快捷键，双击预览保持现有只读行为。

## 测试策略

- 核心集成测试覆盖：成功解散、同名冲突不改盘、额外文件拒绝、事务中途失败回滚。
- IPC 合约测试覆盖 channel、schema 和 fake API 类型。
- 渲染器测试覆盖：卡片开关调用启用/停用、右键菜单顺序和分组菜单、`Ctrl+G`、`F2`、`Delete`、进入组扫描路径、预览双击不被开关点击触发。
- 运行既有单元/集成/渲染器测试、TypeScript、Biome、构建和已有 portable/package/BAT 检查。

## 范围外

本轮不实现剪切/粘贴、系统剪贴板、拖拽菜单替代方案、远端 Git 操作或新的外观设置页面。
