# DNF 补丁管理器操作手册

## 1. 启动与首次设置

1. 双击 `启动DNF补丁管理器.bat`。
2. 第一次启动时等待依赖和 Electron 运行时准备完成。
3. 点击左侧设置图标，在“游戏目录”区域选择 DNF 游戏根目录。
4. 应用直接进入补丁工作区；将一个或多个 `.npk` 文件拖入补丁工作区即可导入。

启动器使用项目目录下的 `node_modules` 和 `out`。如果运行时缺失，会自动执行 `pnpm install --frozen-lockfile` 和 Electron 二进制准备；仍失败时先检查 pnpm、网络和目录权限。

## 2. 补丁库和分类

- 左侧分类树对应 `patch-categories` 下的真实文件夹。
- 侧栏系统入口依次为回收站、全部、未分类、预设和资源社区，下面是可展开的真实分类树。
- “未分类”只显示补丁库根目录中的直接 `.npk`，不会混入分类子目录或组。
- “资源社区”当前是本地占位入口，主区显示“待构建”，不会访问远端。
- 根分类显示当前层的 NPK 和组；默认不会把子分类内容混入父分类。
- 开启“包含子分类”后才查看递归范围。
- 新建分类使用分类栏的加号按钮；分类重命名和删除仍由底层分类服务支持，当前界面不提供入口。
- 分类排序直接拖动分类节点，同级排序会持久化到 `data/category-order.json`。
- 删除分类前必须为空；NPK 或组应先移动或移入回收站。

## 3. 导入、移动和重命名

- 补丁导入仅支持将 `.npk` 文件拖入补丁工作区；不处理 `.img` 或其他后缀文件。
- 补丁库已有内容时，把 NPK 拖入中央工作区即可导入。
- 同路径或同内容的重复项会被报告；同名不同内容不会覆盖已有文件。
- 单选项目后点击“移动”或“重命名”，在对话框中选择目标位置或输入新名称。
- 多选后移动会作为一个原子批次执行，任何一步失败都会回滚。

## 4. 选择、筛选和视图

- 普通点击单选。
- `Ctrl` 点击多选，`Shift` 点击连续选择，拖动空白区域可框选。
- 工作区标题行的搜索框按名称或相对路径过滤。
- 工作区控制行在“包含子分类”左侧切换网格/列表视图。
- 选中项目后，主工作区操作条提供启用、重命名、移动、打组、加入预设和移入回收站按钮。

## 5. 组

1. 在同一分类中选择至少两个 NPK。
2. 点击选中操作条的“打组”。
3. 输入组名称并确认。

组是真实文件夹，目录内包含 NPK 和 `.dnf-group.json`。组可以整体移动、重命名、启用、停用、移入回收站和恢复。把 NPK 移入已有组等同于移动真实文件。

## 6. 启用和停用

- 先设置游戏目录，再选择一个或多个补丁，点击“启用”。
- 启用会把库内 NPK 复制到游戏根目录，并写入安装记录。
- 停用只删除仍与安装记录哈希一致的游戏文件。
- 如果游戏文件被外部修改或同名目标内容冲突，操作会停止，不覆盖文件。
- 组启用/停用等价于组内所有 NPK 的一个全有或全无批次。

## 7. 本地预设

- 预设只保存现有 NPK 的库内相对路径引用，不复制或移动补丁文件。
- 在网格或列表中选中一个或多个 NPK，点击“加入预设”，输入名称即可创建；也可以在同一对话框追加到已有预设。
- 点击侧栏“预设”查看引用数量和缺失数量。选择预设可查看每个引用路径。
- “安装”采用叠加语义，只启用预设中仍存在的补丁，不停用其他已启用补丁。
- 被删除或移动的引用会显示为缺失；安装时跳过缺失项并报告具体路径。
- 删除预设只删除 `data/presets.json` 中的引用，不删除任何 NPK 文件。

## 8. 预览图和壁纸

### 项目预览

双击补丁或组卡片的预览区域，选择图片。补丁预览会复制到该 `.npk` 所在目录，并使用与补丁相同的基础名；只有同目录且基础名匹配的图片才会显示为补丁预览。已有的旧版补丁预览会在启动时迁移到该位置。组预览继续由应用管理的资源目录保存。右键菜单不提供“选择预览图”入口。

### 壁纸与外观

1. 点击左侧设置图标打开设置面板；“游戏目录”区域可更换 DNF 根目录。
2. 壁纸区域提供五个槽位；每个槽位可以导入、激活或删除图片。
3. 外观参数包括色温、饱和度、对比度、缩放、透明度、模糊和水平/垂直位置。
4. 可切换默认界面、透明玻璃和高对比度三套主题；字体外观可配置 Windows 字体和字体颜色。

壁纸和外观状态保存到应用数据目录，图片通过受管 `dnf-asset:` 协议加载。

## 9. 回收站和恢复

- 删除操作先移动到应用数据目录的 `recycle-bin`，不会直接永久删除。
- 打开回收站查看项目原路径、回收时间和类型。
- 恢复前会检查原位置；目标已存在时返回冲突，不覆盖现有文件。
- “清空回收站”需要显式确认，执行后不可通过应用恢复。

## 10. 状态损坏和只读恢复

如果设置、分类排序、安装记录、预览、壁纸、预设或回收清单损坏，应用启动时会进入只读恢复模式：

- 顶部显示损坏文件路径。
- 已有库文件仍尽可能可查看。
- 导入、游戏目录选择、分类修改、移动、分组、启停和回收操作会被拒绝。
- 不要删除损坏 JSON；先复制备份，再按错误消息中的路径和事务日志恢复。

## 11. 数据备份和升级

便携版数据位于 EXE 同级：

```text
DNF补丁管理器.exe
data/
patch-categories/
```

升级前关闭软件并备份 `data` 与 `patch-categories`，升级时只替换 EXE 或整个程序源码，不覆盖用户数据。用户测试 NPK、壁纸和临时截图不属于发布文件。

预设保存在 `data/presets.json`，只包含名称、时间和补丁相对路径；备份和恢复时应与其它 `data` 状态一起处理。

## 12. 明确不支持

软件不提供在线补丁下载、社区分享、作者上传平台、复杂冲突分析、快照、多游戏目录实例、自动更新和逆向保护。
