## [LRN-20260707-001] Git 分支整理先确认主分支关系

**记录时间**：2026-07-07T00:00:00+08:00  
**优先级**：高  
**状态**：待处理  
**范围**：配置

### 摘要
Git 分支整理时必须先区分本地当前分支、远端默认分支和重复分支，再决定统一策略。

### 详情
本次维护中，本地实际工作分支是 `master`，而 GitHub 仓库默认分支一度是 `main`。同时本地还残留多个指向同一提交的重复分支。后续处理这类仓库时，不能只看分支名字，要同时核对 `git branch -a -vv`、`git remote show origin`、`git rev-list --left-right --count`，确认当前分支、远端默认分支、跟踪关系和分叉状态，再决定是否强推、改默认分支或删除重复分支。

### 建议动作
涉及分支整理时，固定先核对本地分支、远端默认分支、分叉关系和工作区状态；只有在确认“以本地为准”后，才执行强推和远端默认分支切换。

### 元数据
- 来源：会话
- 相关文件：`E:\BaiduSyncdisk\codex目录\DNF\.git`
- 标签：git, branch, remote, github
