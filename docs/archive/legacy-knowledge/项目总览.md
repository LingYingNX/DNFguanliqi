# DNF插件管理器项目总览

> 更新日期：2026-07-07

## 项目定位

DNF 补丁管理器是一个 Windows 本地桌面工具，用来管理用户已有的 `.npk` 补丁。它不提供补丁下载，也不修改游戏客户端逻辑，只负责把本地 NPK 文件按真实目录分类、预览、导入、启用、停用、重命名、移动和分组。

## 诞生原因

项目最初是为了解决 DNF 补丁文件长期散乱、启用停用麻烦、分类和预览不直观的问题。核心诉求一直是“本地文件管理器”，不是补丁平台。

从一开始就确定的方向：

- 只管理本地文件
- 操作方式贴近文件夹
- 便携运行，方便替换 exe 更新
- 稳定、简单、后续好维护优先

## 核心数据模型

### 补丁分类

补丁分类就是 `patch-categories` 下面的真实文件夹。软件扫描目录层级并显示在左侧分类树中。

规则：

- 目录就是分类
- `.npk` 文件就是补丁
- 图片文件可作为同名预览图
- 分类计数只统计 `.npk`
- 父目录默认只显示本层文件，不递归混入子目录补丁

### 组

组已经定案为真实文件夹模型。

规则：

- 打组等同于新建文件夹
- 被打组的 NPK 会真实移动进组文件夹
- 组目录内使用 `.dnf-group.json` 标记
- 启用组时安装组内全部 NPK
- 停用组时停用组内全部由软件安装的 NPK
- 组可以像普通补丁一样显示、移动、删除、设置预览图

### 预览图

- 文件预览图通过双击预览区域设置
- 组预览图也通过双击预览区域设置
- 右键菜单里的“选择预览图”入口已经移除

### 便携数据

打包版按 exe 同级目录使用：

```text
DNF补丁管理器.exe
data
patch-categories
```

更新时保留 `data` 和 `patch-categories`，只替换 exe。

## 核心模块职责

- `src/main/main.js`：窗口创建、配置读写、分类扫描、导入补丁、启停补丁、移动 / 删除 / 还原、预览图选择、壁纸保存、打包路径处理
- `src/main/preload.js`：只暴露明确命名的安全 API，不直接暴露 `ipcRenderer`
- `src/renderer/app.js`：渲染分类树、卡片、列表、右键菜单、拖拽、框选、组交互、筛选和提示
- `src/renderer/index.html`：界面结构、弹窗、面板、工具栏
- `src/renderer/styles.css`：界面样式、卡片、列表、左侧分类、壁纸和交互状态

## 已定边界

项目不做：

- 在线补丁下载
- 社区分享
- 作者端上传平台
- 复杂补丁冲突检测
- 快照系统
- 多 DNF 目录实例管理
- 自动更新器
- 软件逆向保护、混淆、加密
