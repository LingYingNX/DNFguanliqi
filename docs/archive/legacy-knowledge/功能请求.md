# DNF插件管理器功能请求

> 更新日期：2026-07-07

## 已实现功能

### 本地补丁管理

- 导入本地 `.npk` 文件
- 拖拽导入补丁
- 按真实文件夹分类补丁
- 显示补丁文件名、大小、日期、启用状态
- 支持网格和列表视图
- 支持卡片尺寸调节
- 支持搜索和启用状态筛选

### 游戏目录绑定与启停

- 选择 DNF 游戏目录
- 启用补丁时复制 NPK 到游戏目录
- 停用补丁时删除由软件记录且内容匹配的目标文件
- 对同名但内容不同的目标文件做基础保护，避免无提示覆盖

### 分类树

- 左侧分类树来自真实文件夹
- 只有存在子目录时才显示展开按钮
- 分类计数只统计 `.npk`
- 支持分类文字颜色和选中色调调整
- 支持前端自定义指针排序，已修复未先选中无法拖动的问题

### 预览图

- 文件预览图通过双击预览区域设置
- 组预览图也通过双击预览区域设置
- 右键菜单里的“选择预览图”已经移除

### 真实文件夹组

- 打组就是新建真实文件夹
- 被选中的 NPK 会真实移动到组文件夹内
- 组目录写入 `.dnf-group.json` 作为标记
- 组可整体启用和停用
- 文件可移动进已有组
- 组支持双击或 F2 重命名
- 组支持移动、删除到回收站和恢复
- 组卡片中间不再显示“组 / 双击进入”，只保留角标提示

### 多选、拖拽和回收站

- 单选
- Ctrl 多选
- Shift 连选
- 框选文件和组
- 拖拽移动文件或组
- 删除到回收站
- 从回收站还原

### 父目录视图

- 父目录默认只显示本层文件
- 子目录内补丁默认不混入父目录
- 如需查看已分类补丁，使用显式切换

### 壁纸和主题

- 5 个壁纸槽位
- 壁纸导入、切换、删除
- 壁纸参数调节：色温、饱和度、对比度、缩放、透明度、模糊、位置
- 两套主题切换
- 分类文字调色

### 打包发布

- 支持 Electron Builder 打包 Windows x64 portable exe
- 支持打包后复制到桌面
- 便携版使用 exe 同级 `data` 和 `patch-categories`
- 更新方式是替换 exe

## 用户已定案的行为边界

- 组是带 `.dnf-group.json` 的真实文件夹，不是纯元数据分组
- 安装组等价于安装组内所有 NPK
- 分类基于真实目录
- 父目录默认不递归显示子目录补丁
- 预览图设置入口以双击预览区域为准
- 分类排序使用前端指针排序，不回退到原生 HTML5 拖拽
- 便携版数据在 exe 同级，不写入旧中文目录或系统 AppData
- 删除、移动、打组、还原都必须按真实文件结果验证

## 明确不做

- 在线补丁下载
- 补丁社区
- 作者上传与分发平台
- 复杂补丁冲突检测
- 快照功能
- 自动更新器
- 多 DNF 目录实例管理
- 软件逆向保护、加密、混淆

## 候选功能

- 批量重命名辅助
- 补丁搜索增强
- 更多排序方式
- 导出当前补丁分类清单
- 更完整的列表模式信息列
- UI 主题预设管理
- 更多键盘快捷键
- 更清晰的异常提示

## [FEAT-20260707-001] 仓库仅保留源码范围

**记录时间**：2026-07-07T00:00:00+08:00  
**优先级**：高  
**状态**：已解决  
**范围**：配置

### 请求能力
远端仓库只上传源码文件，其它运行数据、截图、素材和维护资料不上传。

### 用户背景
用户要把 GitHub 仓库收敛成纯源码仓库，避免把本地补丁数据、验证截图和维护资料一起推到远端，减少仓库噪音，也避免把运行态内容误当成源码发布。

### 复杂度评估
简单

### 建议实现
通过修改根目录 `.gitignore` 并对已跟踪的非源码文件执行 `git rm --cached`，保留本地文件但从 Git 跟踪和远端仓库中移除，只保留 `dnf-patch-manager` 下的源码与构建必需文件。

### 元数据
- 频率：首次
- 相关功能：repository-cleanup, source-only
