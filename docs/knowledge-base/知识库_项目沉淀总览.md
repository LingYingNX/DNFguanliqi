6. 会话恢复和知识沉淀先做来源核对；当前源码、Git 状态和当前测试优先于旧摘要。
7. 外部服务只接收用户明确授权的最小脱敏 payload；不上传私有源码或完整样式。
8. 知识库保持五文件根布局；源码、Git、运行数据和构建产物留在源码工作副本。
9. Windows PowerShell 命令按 RTK 约定执行；复杂嵌套脚本拆开，避免外层变量展开和编码误报。
