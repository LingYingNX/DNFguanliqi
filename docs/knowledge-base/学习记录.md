## [LRN-20260803-001] 跨会话证据优先

**状态**：promoted  
**来源**：Codex transcript 审阅

同一 transcript 可能包含多个 session_meta、标题变化、父子会话和不同工作树。记录会话时必须同时核对投影事件、当前源码、Git 状态和测试输出；旧恢复报告只能作为线索。项目当前事实优先于历史摘要。

维护动作：

- 按 cwd 筛选候选会话。
- 按会话 ID 和事件内容去重。
- 记录来源路径、时间、ID、已完成/部分完成/未完成和不一致。
- 不复制完整 transcript，不把旧测试数字写成当前通过证据。

## [LRN-20260803-002] 真实文件和真实窗口优先

**状态**：promoted  
**来源**：多轮文件操作、安装和 Electron 会话

分类、组、移动、回收、启停、恢复等操作必须同时验证：

1. 磁盘目录和 NPK 结果。
2. 状态 JSON、顺序文件和事务结果。
3. renderer 用户意图。
4. 真实 Electron 窗口、IPC 和异步写入。

只通过 mock 或单测不能证明用户工作流完成。

## [LRN-20260803-003] Windows 式框选的事件边界

**状态**：promoted  
**来源**：019fc14e-9476-7ff1-9d81-ceea2ed69ca3

卡片框选不是只放行预览热点。手势面要覆盖主卡片管理面板的空白、内边距、网格间隙和预览热点，同时排除按钮、表单、菜单和卡片主体的原生拖放。应明确检查 pointerdown、pointermove、pointerup、pointercancel、draggable 和失焦清理。

## [LRN-20260803-004] 分类跨层级移动契约

**状态**：promoted  
**来源**：019fc14e-9476-7ff1-9d81-ceea2ed69ca3

用户确认的落点规则：

- 目标行中部：移动为目标子级。
- 目标行上边缘：移动到目标同级之前。
- 目标行下边缘：移动到目标同级之后。

后端必须原子校验并执行真实目录迁移、嵌套内容保留、顺序路径迁移和导航刷新；必须拒绝根目录、自身/子目录和同名覆盖。

## [LRN-20260803-005] 测试超时的诊断方法

**状态**：promoted  
**来源**：019fa2a8、019fb76e、019fc14e

全量并行出现超时时，先保留首次失败，再单文件、单 worker 或串行复跑。隔离通过只能说明资源竞争可能存在，不能删除首次失败证据；隔离仍失败时必须按真实回归处理。

## [LRN-20260803-006] 外部数据外发边界

**状态**：promoted  
**来源**：019fc612-3c79-7882-8544-d2f121c46133

本地只读审查、脱敏摘要和局部 mock 与上传私有源码到外部设计服务是不同权限。外部服务调用必须先明确 payload、目的地和授权；默认只使用本地证据和最小脱敏摘要。

## [LRN-20260803-007] 知识库分层

**状态**：promoted  
**来源**：项目既有知识记录和本次用户请求

源码维护位置是 E:\codex目录\DNF；知识库只保留五个根文件。项目代码、Git、依赖、运行数据、构建产物、NPK 和截图不进入知识库。新经验先进入源码仓库 .learnings，再提炼到知识库总览或三份记录文件。
