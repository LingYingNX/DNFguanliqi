# DNF 补丁管理器功能需求

## 已实现

- 本地 NPK 导入、拖放导入、重复/冲突预检。
- 真实目录分类、创建/重命名/删除/同级排序和递归查看。
- 单选、Ctrl 多选、Shift 连选、框选、搜索、启用筛选、网格/列表和卡片尺寸。
- 真实文件夹组、组标记、组内 NPK 整体启停、移动、重命名、回收和恢复。
- 游戏目录持久化、单项/批量/组启用停用、目标哈希保护和路径边界保护。
- 预览图导入与生命周期绑定、五槽壁纸、主题、颜色和壁纸显示参数。
- 回收站、恢复冲突保护、显式清空确认。
- 损坏状态只读恢复、事务失败日志、原子 JSON 写入和 portable 打包。

## 用户已确定的边界

- 组必须是真实文件夹，不使用虚拟标签替代。
- 删除、移动、打组、启停和恢复必须验证真实文件结果。
- 预览图通过双击预览区域设置，右键菜单不提供同名入口。
- 便携版使用 EXE 同级 `data` 和 `patch-categories`。
- 不访问远端作为本地维护前提。

## 明确不做

- 在线补丁下载、社区分享、作者上传平台。
- 复杂冲突分析、快照、多游戏实例、自动更新器。
- 逆向保护、混淆、加密和修改游戏客户端逻辑。

## 后续候选

- 批量重命名辅助、更多排序方式、补丁分类清单导出。
- 更完整的列表信息列和主题预设管理。
- 更多键盘快捷键和更清晰的异常详情。

新请求先判断是否违反“本地文件工作台”边界，再写入此文件并关联实现计划。
